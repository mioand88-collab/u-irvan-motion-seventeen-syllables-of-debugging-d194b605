# Seventeen Syllables of Debugging

A haiku about debugging, in classic 5-7-5 form: a cursor blinking at three in the morning, a log line insisting everything was fine, and a bug that turned out to be wearing the author's own name.

```
Cursor blinks at three
a log line swears it was fine
the bug wore my name
```

## Run it

```sh
node main.ts
```

This writes the haiku to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` if unset).
